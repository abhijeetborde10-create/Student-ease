# Student Ease

A beginner-friendly MVP for students moving to a city for 11th/12th, CET/JEE or college who need nearby PG/hostel/mess options.

## Features
- Student registration/login
- Owner registration/login
- College/type/audience/gender filters
- Maximum rent and distance filters
- Lowest-rent / nearest sorting
- PG, hostel and mess listings
- Owner dashboard to publish listings
- SQLite local database with demo data

## Run
1. Install Python 3.10+
2. Open terminal in this folder
3. `pip install -r requirements.txt`
4. `streamlit run app.py`
5. Browser opens at the local Streamlit address.

Demo student:
student@studentease.demo / 1234

owner@studentease.demo / 1234

## Important
This is an educational MVP/prototype. For a real deployment, passwords must be hashed, owner/student identities verified, listings moderated, and a proper hosted database/authentication system should be used.
